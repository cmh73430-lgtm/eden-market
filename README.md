# eden-market

**앱 주소: https://cmh73430-lgtm.github.io/eden-market/** (PC·폰 즐겨찾기/홈 화면에 추가해서 쓰기. 입력한 기록은 각 기기 브라우저에만 저장되고 여기에 올라오지 않습니다.)

Eden Cockpit(개인 장전 체크 앱)의 **자동 연동용 공개 시장 숫자**만 모으는 저장소입니다. 개인 매매 기록·손익·메모는 여기에 없습니다.

- 평일 07:05·08:05 KST: 나스닥100 선물·원달러·SOX·VIX·WTI·미 10년 금리, 미국 대응주 8묶음, 코스피200 야간선물(야간 종가 ÷ 전날 주간 종가)
- 평일 16:20 KST: 코스피·코스닥 마감 등락률, 투자자별 수급(외국인·기관, 억원)
- 결과: `auto/<날짜>.json`, `auto/latest.json` (GitHub Actions `collect` 워크플로가 저장)
- 출처: 네이버 증권(모바일 웹 JSON), 업비트, 야후(예비), TradingView 공개 스캐너(야간선물). 비공식 경로라 바뀌면 값이 빠질 수 있고, 앱은 빈 칸을 손 입력으로 남깁니다.
- 수집기 코드는 비공개 앱 저장소에서 `scripts/sync-eden-market.sh`로 복사해 옵니다.

투자 권유가 아니며, 숫자의 정확성을 보장하지 않습니다.
